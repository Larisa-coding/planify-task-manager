# Planify

Личный планировщик задач. Задачи делятся на личные, рабочие и желания. Есть календарь, архив и аналитика. Всё хранится в браузере, аккаунт не нужен.

Сайт: https://planify-task-manager.vercel.app

## Что умеет приложение

- Создавать, редактировать и удалять задачи.
- Делить задачи на три категории: личное, работа, желания.
- Ставить срок, приоритет, статус, теги и цвет.
- Показывать дедлайны в календаре.
- Складывать выполненные и удалённые задачи в архив и восстанавливать их.
- Считать простую аналитику по задачам.
- Переключать тёмную и светлую тему, русский и английский язык.

## Стек

- React 18 и TypeScript
- CSS (стили собраны в `src/App.css`, Tailwind подключён как база)
- localStorage для задач
- date-fns для дат
- Lucide для иконок

## Как запустить

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Приложение откроется на http://localhost:3000

Сборка:

```bash
npm run build
```

Готовые файлы лежат в папке `build`.

## Как хранятся данные

Задачи записываются в `localStorage` под ключом `planify_tasks_v2`. Они остаются после перезагрузки и не уходят на сервер. Удаление не стирает задачу сразу: она попадает в архив, оттуда её можно вернуть или удалить навсегда.

Если на устройстве остались задачи из старой версии (IndexedDB), приложение один раз читает их и переносит в `localStorage`.

## Структура

```
src/
├── App.tsx                 # экраны и открытие формы
├── components/
│   ├── Dashboard/          # главная
│   ├── Tasks/              # список и форма задачи
│   ├── Calendar/           # календарь
│   ├── Archive/            # архив
│   ├── Analytics/          # аналитика
│   └── Layout/             # шапка, меню, нижняя панель
├── database/
│   ├── taskStore.ts        # задачи: чтение и запись
│   └── db.ts               # разовый перенос из старой базы
├── hooks/useTasks.ts       # подписка экранов на список задач
├── context/                # язык и тема
├── i18n/translations.ts    # русские и английские тексты
└── types/index.ts          # типы задачи
```

## Экраны

| Экран | Зачем |
| --- | --- |
| Главная | сводка по категориям и ближайшим срокам |
| Задачи | все задачи или одна категория |
| Календарь | задачи по дате |
| Архив | выполненные и удалённые, восстановление |
| Аналитика | сводка за неделю, месяц или всё время |
